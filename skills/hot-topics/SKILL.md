# Hot Topics Skill (热门话题获取与选题评估)

本技能指导 AI Agent 通过访问 **今日热榜 (https://tophub.today/)**，动态且健壮地抓取全网主流平台的实时热门话题，并为自媒体与内容创作者提供爆款选题分析。

> **核心设计原则（高健壮性）**：
> - **零硬编码依赖**：严禁死记 HTML Class 名或节点 ID，全程依靠语义理解与页面结构分析。
> - **外链直达优先**：优先提取指向第三方源站（如微博搜索、知乎问题、36氪原文章）的直达 URL。
> - **容错降级保护**：若个别榜单请求失败或超时，自动忽略异常榜单，基于已成功获取的榜单完成聚合展示。
> - **人机直接交互**：以精炼美观的 Markdown 报告直接呈现给用户，方便用户在当前对话中直接选定选题。

---

## 核心执行流程

### 阶段一：访问首页并提取目标榜单跳转 URL

1. **访问首页**：调用网页读取/访问工具获取 `https://tophub.today/` 页面内容。
2. **提取榜单链接**：
   - 寻找榜单标题与分类，提取目标平台的榜单跳转 URL（如相对路径 `/n/...` 补全为完整 URL `https://tophub.today/...`）。
   - **注意**：阶段一仅用于检索目标榜单的跳转 URL 链接，**严禁提取或缓存首页上其他非目标平台的内容词条**。

---

### 阶段二：依据意图比对并精选目标榜单 URL

Agent 需将用户输入的意图与阶段一实时获取到的全量榜单 URL 进行匹配：

1. **确定抓取目标**：
   - **默认/无明确指令（关键规则）**：若用户未提供明确的目标平台或领域指令（如仅输入“看下热点”或直接触发技能），**必须且仅锁定以下 7 个指定榜单**作为数据抓取来源：
     1. **知乎**（知乎热榜）
     2. **微信**（微信 24h热文榜）
     3. **36氪**（36氪 24小时热榜）
     4. **掘金**（掘金热门文章/热榜）
     5. **雪球**（雪球热股/热门话题）
     6. **华尔街见闻**
     7. **新浪财经**
   - **通用/多领域查询**（如“今天有什么热搜/大新闻”）：可选择综合大榜。
   - **垂类/特定领域查询**（如“科技热点”、“财经动态”）：匹配对应的专业榜单。
   - **特定平台指定**（如“看下微博和知乎”）：直接锁定用户指定的平台。
2. **限定数据输入源**：在无明确指令时，**只将上述 7 个榜单作为输入进入阶段三及后续流程**，严禁访问或拉取任何其他榜单的数据。

### 阶段三：仅访问并提取这 7 个目标榜单的话题数据

依次访问阶段二锁定的目标榜单 URL（在无指令默认模式下，**严格只访问上述 7 个榜单 URL**）：

1. **识别榜单结构**：识别有序列表、表格（`<table>`）或卡片流（`<div>` 循环）。
2. **提取核心字段**：
   - **排名 (Rank)**：寻找 `1, 2, 3...` 序号。
   - **话题标题 (Title)**：提取核心文本/词条。
   - **直达原链 (URL)**：优先提取 `<td><a href="...">` 中指向第三方平台（如 `zhihu.com`, `36kr.com`, `xueqiu.com`）的直达链接；若无外链，保留今日热榜内跳转链接。
   - **热度/量级 (Hot Metrics)**：识别如 `xxx万`、`xx.x万热度` 等文本标记。
3. **单榜异常容错**：若某单个榜单访问失败（404/超时），静默忽略该榜单，继续抓取其余有效榜单。

---

### 阶段四：对所抓取话题进行去重聚合与内容创作价值评估

**仅基于阶段三抓取到的候选话题数据集**，进行去重、交叉聚合与创作价值评估，**最终汇总精选呈现的话题总量严格限制在 10 个以内（Top 10）**。

#### 1. 话题去重与交叉聚合

1. **语义去重合并**：识别阶段三抓取结果中指向同一下点/新闻事件的相关词条（如知乎“iPhone 18 价格预测”、36氪“苹果供应链爆料”合并为同一主题）。
2. **分类标签**：为每个话题打上领域标签（如 `[科技/AIGC]`、`[商业财经]`、`[开发者/前沿]`）。
3. **多源标注**：标注话题在该 7 榜中的出处及排名（如 `来源：知乎热榜(#1)、36氪热榜(#2)`）。
4. **综合热度排序与数量限制**：优先将多端共振热点进行置顶排序，**全局仅保留并输出综合热度最高的 Top 10 核心话题**。

#### 2. 内容创作参考价值评估维度

针对筛选出的每个聚合话题，给出**“创作参考价值分析”**：

- **综合评级 (Rating)**：使用 1~5 颗星评分（`⭐⭐⭐⭐⭐`）。
- **共振与时效**：评估是“单平台局部发酵”还是“全网多端共振”，标注时效性（如 `⚡ 突发急升` 或 `🔥 持续发酵`）。
- **适合赛道与形式**：分析适合图文、短视频、深度科普解说或正反论战（如“适合短视频金句”、“适合长图文拆解”）。
- **选题切入点建议**：给出 1~2 句具体的选题立意与互动引导建议。

## 健壮性与容错机制

1. **页面改版自适应**：DOM 结构变更时，转为全文本 Markdown 语义扫描，识别数字序号与词条标题。
2. **无硬编码依赖**：不写死 CSS 类名与节点 ID，全程以实际 HTML 语义解析为准。
3. **单榜异常降级**：个别榜单请求失败时不影响整体运行，基于成功获取的榜单正常聚合。
4. **输出总量封顶**：去重聚合后最终生成的话题列表严格控制在 **Top 10 以内（最多 10 个）**，避免过多长尾内容造成信息过载。
5. **外链直达保护**：提取超链接时优先选取第三方目标平台 URL，方便用户一键直达源头。
