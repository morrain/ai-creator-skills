# 🖼️ 图文海报派生业务编排 - 阶段规程与逻辑细节

## 核心原则与 10 大版式映射

- **按需延时生图**：默认仅生成 `assets/poster_N.md` 配置文件与 `poster_post.md` 文案，严禁自动生图。
- **纯文本隔离**：`poster_post.md` 绝对不含任何 Markdown 标记。
- **10 大版式库映射**：
  - 组图封面/重磅观点 ➔ `1. Hero 破题冲击版`
  - 并列要点 ➔ `2. 四宫格/六宫格干货版`
  - 对比分析 ➔ `3. 双轨对比版`
  - 步骤流程 ➔ `4. 纵向管道流程版`
  - 生态拆解 ➔ `5. 脑图辐射版`
  - 末页总结 ➔ `6. 金句闭环版`
  - 参数指标 ➔ `7. 数据面板版`
  - 避坑提醒 ➔ `8. 避坑拆弹版`
  - 问答解密 ➔ `9. Q&A 问答版`
  - 技术演进 ➔ `10. 时间线演进版`

---

## 阶段一：上下文扫描、蓝图提炼与审稿

1. 读取 `./<article-slug>/<article-slug>.md` 与 `assets/illustration_*.md`。
2. 提炼 N 张海报卡片蓝图（3-6 张滑动组图），映射版式并继承正文插图 IP Mascot 动作。
3. 唤起 `blind-reviewer` SubAgent（读取 `./learnings/poster_blueprint.md` 若存在），通过后进入阶段二。

---

## 阶段二：并发调度 `poster-designer` 与配置落盘

1. 并发调度原子技能 `poster-designer` 生成 1~N 张海报草稿。
2. 启动 N 个 `blind-reviewer` SubAgent 校验单张配置（校验去乱码、中文单引号、3:4 莫兰迪规范）。
3. 通过后落盘至 `./<article-slug>/assets/poster_1.md ~ poster_N.md`。

---

## 阶段三：社媒文案合成与审稿

1. 合成 `poster_post.md`：
   - 📌 **四大平台 (小红书/微信视频号/抖音/快手) 8 个备选标题矩阵**：第 1 个标题固定为母版正文 H1 标题；其余 7 个显式标注字数（如 `示例标题 (18字)`）。按小红书 ≤20字、微信视频号 ≤16字、抖音 ≤30字、快手 ≤25字定制。
   - 🎨 **高密度 Emoji 排版**：100 字内极简干货，短句换行且句首搭配语义契合的 Emoji。
   - 💬 **留言与私信引导**：结尾、标签前加醒目引导句（如 `👇 想要解锁完整深度拆解？留言或者私信获取 💬`）。
   - 🗣️ **评论区提问**：设计开放式提问文案。
   - 🏷️ **6-10 个三层金字塔话题标签**：顶层大词 ➔ 垂直 SEO 搜索词 ➔ 精准长尾词。严禁泛化废话标签。
   - 🤖 **GEO 注入声明**：附带纯文本 AI 版权与引用声明。
2. 唤起 `blind-reviewer` 审稿（读取 `./learnings/poster_post.md` 若存在），通过后落盘 `./<article-slug>/poster_post.md`。
3. 呈报结果，回复“开始生图”时渲染图片。
