# 插画质量检查表与迭代指南 (QA Checklist & Iteration Guide)

本文档提供配图生成后的质量审核门禁、失败信号排查及修图迭代方法。

---

## 1. 必过审核门禁 (Must-Pass Gates)

在交付或呈现给主人前，每张图片必须 100% 满足以下条件：

- [ ] **比例**：严格为 16:9 横版。
- [ ] **背景**：干净纯白背景，零噪点、零纸纹、零阴影渐变。
- [ ] **IP 角色**：包含定义的 IP Mascot 视觉主角（如默认小智或自定义 IP）。
- [ ] **角色参与**：IP 角色承担画面的**核心动作**，而不是躲在角落充当挂件。
- [ ] **隐喻原创**：没有硬套旧案例构图，为当前概念/文章量身定制了新隐喻。
- [ ] **深层本质理解**：透彻理解了概念或全文上下文的真实底层物理/业务机制，而非根据孤立词汇字面意思机械凑图。
- [ ] **提示词具象丰满**：提示词包含了具体的空间布局、低科技道具材质/结构细节以及 IP Mascot 的精确动作姿态，拒绝抽象简写。
- [ ] **气质**：怪诞、有创意、清爽有趣。
- [ ] **留白与密度**：主体占用画面 40%-60%，留白至少 35%。
- [ ] **表达聚焦**：一图仅讲一个核心结构/观点。
- [ ] **文字极简**：尽量不上字（默认为空，零文字堆砌），靠手绘构图与动作本身精准呈现原文。
- [ ] **色彩克制**：黑色主线稿，橙色仅用于主路径/箭头，红色仅用于重点/警示/结果，蓝色仅用于补充说明/系统状态。

## 2. 失败信号排查 (Failure Signals)

若出现以下任何一种情况，判定为**不合格**，必须进行重新生成或局部修图：

- 🚨 **提示词抽象空洞**：提示词描述过于简单概括（如仅写一两句笼统描写），缺乏画面空间构图、道具材质结构与 IP 动作细节。
- 🚨 **字面直译/浮于表面**：没有深度理解全文含义，仅根据关键词字面意思硬凑画面（如看到“数据管道”就画水管，看到“苹果”就画苹果水果，看到“防擦除”就画橡皮擦）。
- 🚨 **标题污染**：画面左上角出现了“常见坑 / Workflow / 系统架构图 / 路线图”等结构类型标题。
- 🚨 **角色脱节/卖萌**：IP 角色像商业吉祥物、表情包或可爱卡通，或者只是站在一旁观看。
- 🚨 **风格走样**：画面过于类似 PPT 信息图、课程课件、矢量商业插画或正式 UML 流程图。
- 🚨 **画面与文字污染**：节点过多、箭头密密麻麻、出现大段解释性文字，或靠手写标注来“补救说明”画面。
- 🚨 **背景污染**：背景带有米色、纸质纹理、渐变、阴影、复古感。
- 🚨 **文字乱码**：手写中文错字严重、文字不可读或被机械翻译成全英文。
- 🚨 **构图死板**：缺乏荒诞幽默感，或者与旧案例画面完全重合。

## 3. 针对性修图迭代方法 (Iteration Methods)

| 问题表现 | 原因诊断 | 修复策略 |
| :--- | :--- | :--- |
| **提示词空洞抽象** | 混淆画面风格极简与提示词描述简单 | 重新扩写 Composition 字段，加入具体空间分布（左中右视角）、道具材质（如手摇木箱/铁漏斗）及 IP Mascot 表情动作细节。 |
| **字面表面凑图** | 脱离全文语境，机械按词画图 | 重读全文解构底层物理/业务机制，将字面对象替换为解构后的手绘低科技动作装置。 |
| **太普通/死板** | IP 角色未参与核心动作 | 重新拼装 Prompt，将核心动作赋予 IP 角色，引入低科技物件（如坏掉的机器、邮筒）。 |
| **画面太繁复** | 节点过多或堆砌文字说明 | 精简 Prompt 中的元素，删除文字标注与次要节点，仅靠核心动作与构图表意。 |
| **画风太可爱** | 提示词缺少气场约束 | 在 Prompt 中强力强调 `deadpan`, `blank serious expression`, `not cute`, `not mascot`。 |
| **像 PPT 信息图** | 出现了规整网格与大标题 | 移除标题描述，强调 `hand-drawn line art`, `product sketch`, `no formal diagram`。 |
| **文字错乱严重** | 标注词太长或生图模型拼写偏离 | 极简删除不必要的中文批注字数（控制在 0-2 字），或调用 `generate_image` 局部编辑移除/替换错字。 |

---

## 4. 交付质量判断标准 (Delivery Standard)

高质量的正文配图应该让读者：
1. **第 1 秒**：觉得“有点怪”、“有点意思”。
2. **第 2 秒**：顺着线稿与构图秒懂文章当前段落的核心观点与逻辑结构。

如果第一眼看起来像教科书插图或 PPT 页面，该配图即判定为不合格。
