# 构图模式与原创隐喻规则 (Composition Patterns & Original Metaphors)

本文档定义插画配图的 8 种基础结构类型、原创隐喻生成方法以及禁用旧构图的反复刻规则。

---

## 1. 8 种基础结构类型

选择最匹配当前段落认知锚点的一种结构即可，切忌在同一张图里混用过多种构图。

### ① Workflow 流程
- **适用场景**：输入 -> 处理 -> 输出、内容生产管线、AI 工作流、自动化链路。
- **构图表达**：左侧输入，中间 IP 角色或怪异机器处理，右侧输出；使用橙色箭头表达主流向。

### ② 系统局部
- **适用场景**：信息来源、过滤器、数据库、渲染器、Agent 系统局部组件。
- **构图表达**：只展示 3-5 个核心模块，IP 角色参与其中一个关键动作（如在接口处插拔）。

### ③ 前后对比
- **适用场景**：混乱/有序、手动/自动、分散/收拢、焦虑/稳定。
- **构图表达**：左侧展示混乱状态，右侧展示稳定状态，中间用橙色流动箭头连接；角色状态可更具戏剧性。

### ④ 角色状态
- **适用场景**：用户痛点、创作者困境、工具过多、信息过载焦虑、卡住到跑通的转变。
- **构图表达**：2-4 个分立的小状态，通过 IP 角色的动作与道具姿态差异直接展示状态演变，极简使用文字。

### ⑤ 概念隐喻
- **适用场景**：内容工厂、信息仓库、脑内黑盒、工作流机器、自动日报。
- **构图表达**：一个占据主体的怪异物件或机器，少量输入，一个核心输出，极具视觉记忆点。

### ⑥ 方法分层
- **适用场景**：方法论框架、系统层级、能力栈、内容架构分层。
- **构图表达**：一层层手绘盒子或方块，不画正式的金字塔；IP 角色在旁搭建或搬运。

### ⑦ 地图路线
- **适用场景**：从想法到上线、用户体验路径、内容承接路径、学习进阶路线。
- **构图表达**：一条弯曲的轻柔手绘路径，搭配少量节点，IP 角色牵引线缆或在路径上行走。

### ⑧ 小漫画分镜
- **适用场景**：失败到成功的过程、真实踩坑吐槽、使用前后的动态变化。
- **构图表达**：2-4 个连续小格子，每格仅表达一个极简动作。

## 2. 原创隐喻生成法 (Context-Aware Metaphor Creation)

结合深入理解的概念本质与机制重新发明视觉隐喻，严禁机械照搬旧图或孤立字面直译。

### 四步推演法 (4-Step Metaphor Deduction)

0. **深层本质机制解构 (Deep Essence Deconstruction)**：
   深入剖析该段落/概念背后的**真实底层矛盾、本质逻辑或物理/业务机制**（若处于工作流且提供有全文上下文，需结合全文综合解构；若仅有单一认知锚点，透彻解构概念背后的本质转折）。拒绝根据孤立词汇的表面字面意思构思画面。
1. **抽象概念转换为物理动作 (Concept to Physical Action)**：
   根据深层机制提取动作：卡住、漏掉、变重、分拣、沉淀、发酵、开门、折叠、拆包、回流、焊接、挤压。
2. **系统结构转换为低科技物件 (System Structure to Low-Tech Props)**：
   旧机器、纸箱、抽屉、水管、邮筒、怪异表盘、天平、井、梯子、漏斗、压面机、晾衣绳、怪异工位。
3. **让 IP 角色承担核心动作 (IP Mascot Core Action)**：
   角色不能站在一旁观看，必须卡在机器缝隙里、拉线、守门、搬运、修补、称重、扶梯子、记录或把素材塞入怪异装置。

### 可用低科技物件池
- 纸箱、抽屉、旧机器、漏斗、天平/秤、邮筒、门、井、梯子、水管、线团、闸门、转盘、黑盒、打孔器、压面机、晾衣绳、怪异工位。
- *使用原则*：一张图只选 1-2 个物件，切勿堆砌。

### IP 角色动作池
- 拉、扛、塞、捞、压、称、缝、剪、拧、守、推、接、拆、标记、回收、插拔。
- *使用原则*：动作必须严格服务于核心意思，切忌为了怪异而怪异。

## 3. 反复刻与反字面直译规则 (Anti-Replication & Anti-Literal Rules)

### 🚫 严禁字面浮浅直译 (Strict Prohibition of Literal Surface Matching)
绝对禁止对文章词汇进行机械表面对照画图（“见词画图”），必须转义为全文上下文的真实机制：
- 🚫 **看到“苹果”画水果苹果** ➔ 应解构为全文对应的生态封密机制、接口限制或硬件管辖实体。
- 🚫 **看到“防擦除/防止擦除”画橡皮擦** ➔ 应解构为数据持久化落盘、防护网卡扣或防止规则被风吹走/抹去的手绘机械锁定装置。
- 🚫 **看到“数据管道”画水管** ➔ 应解构为流量分流阀门、多路接线盘或纸箱传送分配结构。
- 🚫 **看到“防火墙”画带火的墙** ➔ 应解构为带有安检闸口、透视镜或筛选筛网的手绘关口。

### 🚫 严禁复用旧图构图 (Anti-Replication Rules)
除非用户明确要求“复刻某张旧图构图”，否则**绝对禁止**直接复用以下过往常见构图：

- 🚫 传送带中间有两个断点。
- 🚫 角色在内容机器里拉动判断闸杆。
- 🚫 角色变成漏斗分拣流量/信任/转化。
- 🚫 角色拿着刀切“素材鱼”。
- 🚫 角色牵着“承接路径”线缆。
- 🚫 角色拉动三层信息源线缆。
- 🚫 三个角色分别拿喇叭、搭桥、开门。
- 🚫 角色盖章与话术工具箱。
- 🚫 角色举警告牌在“常见坑路径”旁看坑。

**原则**：即便遇到同类主题，也必须深度理解全文上下文并更换全新的视觉隐喻（例如“一鱼多吃”可以画角色把一个纸团压成多种形状，而不是切鱼）。
