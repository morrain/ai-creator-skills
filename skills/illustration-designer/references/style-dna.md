# 风格 DNA (Visual Style DNA Specification)

本文档定义 `illustration-designer` 技能的视觉 DNA、色彩规范与绝对禁忌，确保所有生成的正文配图具备统一、清爽、怪诞且专业的手绘产品草图感。

---

## 一句话视觉定位

**纯白、极简、手绘、留白、克制、怪诞、产品草图感、中文手写感、结构清晰但不说明书。**

像一个长期从事 AI、产品、设计、开发工具的人，在白纸上随手画出来的一张结构解释草图。

---

## 必须遵循的视觉标准

- **16:9 横版正文配图**。
- **纯白背景**：绝对干净的纯白（`#FFFFFF`），拒绝米色、暖灰、纸张纹理、渐变、阴影、噪点或复古纸感。
- **黑色手绘线稿为主**：细线、轻微抖动、不机械、不矢量、不厚重描边。
- **大量留白**：主体占画面约 40%-60%，至少保留 35% 以上空白，最好有一整块安静的留白区域。
- **少量中文手写批注**：最多 5-8 处，每处尽量 2-8 个字。
- **一图一意思**：一张图只表达一个核心动作、结构、状态或隐喻。
- **自然表达结构**：结构靠画面逻辑表达，绝对不要在图上直接书写结构类型名称（如不要写“ Workflow 流程图”）。

---

## 颜色系统 (Color System)

- **黑色 (Black)**：主体线稿、IP 角色、框线、结构、主要文字、主体物件。
- **橙色 (Orange)**：主流程、路径、流向箭头、自动化流向、从 A 到 B 的移动关系。
- **红色 (Red)**：重点批注、关键问题、情绪点、断点、警示提醒、核心结果。
- **蓝色 (Blue)**：补充说明、脑内状态、系统状态、第二层解释、AI / Assistant / 自动化提示。

> **注意**：蓝色并非每张图必用。配色保持极度克制，宁少勿多。

---

## 绝对禁忌黑名单 (Prohibitions)

- 🚫 **绝对禁止** 商业插画风格 / 精致扁平插画。
- 🚫 **绝对禁止** PPT 信息图 / 课程课件 / 商务图表。
- 🚫 **绝对禁止** 正式流程图 / 规范 UML 架构图。
- 🚫 **绝对禁止** 可爱卡通海报 / 儿童插画 / 卖萌吉祥物。
- 🚫 **绝对禁止** 科技感 UI / 真实 App 截图 / 3D 金属渲染 / 复杂科幻特效。
- 🚫 **绝对禁止** 复杂背景、渐变、阴影、纸纹。
- 🚫 **绝对禁止** 在画面左上角写“Workflow 流程图 / 系统架构图 / 常见坑 / 路线图”等类型标题。

---

## 审美与气质方向

要**怪诞、创意、有意思、简洁清爽、天马行空**；
绝对不要可爱、幼稚、繁复死板。
