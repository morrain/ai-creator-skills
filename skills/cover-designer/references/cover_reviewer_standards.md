# Cover Reviewer Standards (封面设计盲审质检标准)

本标准供独立 SubAgent 盲审引擎 (`blind-reviewer`) 对 `cover-designer` 技能导出的 `assets/cover.md` 进行严格质检打回。

---

## 1. 结构完整性门控 (Hard Schema Gates)

- 必须输出标准的 `assets/cover.md` 格式：
  - 必须包含 `# 封面设计：[爆款主标题]` 标题。
  - 必须包含 `## 封面元数据`（指明目标平台、核心主题、互动范式）。
  - 必须包含 `## 🔵 中文确认版 封面视觉与爆款排版设计`（明确爆款主标题、评论引导标记、物理隐喻构件与 IP 姿态）。
  - 必须包含 `## 🟢 英文生图版 Prompt (按平台区分)`（分块提供小红书 3:4、微信 2.35:1、视频号 9:16 等专属生图 Prompt）。

---

## 2. CTR 点击率与视觉冲击力审查 (CTR & Visual Impact Gate)

- 🔤 **爆款 Hook 标题**：主标题字号必须标记为 $\ge 72px$ 极粗体，控制在 10~14 字以内，具备强烈的痛点/悬念感。如果标题过于平淡、书面化或超过 16 字，盲审引擎必须打回！
- 🎨 **视觉焦点与物理隐喻**：画面必须包含具象 2D 物理隐喻（如管道、天平、齿轮、问号防护罩、爆表仪表盘），**绝对禁止描述为平淡无奇的纯文字卡片浮动**！
- 🤖 **IP Mascot 姿态**：IP Mascot 必须呈现具备发问/探查/指引张力的定格动作，严禁单向僵硬站立或无意义卖萌。

---

## 3. 评论引力与互动标记按需审查 (Content-Driven Comment Engagement Gate)

- 💬 **评论互动钩子条件触发**：
  - **若内容具备天然互动切口**（如对立路线、避坑多选、悬念猜想、痛点吐槽或认知差）：封面设计必须严格匹配 `references/engagement_recipes.md` 中的爆款范式之一，并在中文方案与英文 Prompt 中配置评论区引导标记（如 `"👉 评论区留下你的观点"`）。
  - **若内容为硬核原理/干货指南/流程解剖（无天然评论切口）**：**充许且鼓励将评论引导标记设为 `null`**。盲审引擎严禁强求硬塞机械化的套路引导语，应重点审查 H1 爆款标题的干货吸引力与 2D 物理隐喻的精妙度！强塞生硬套路者打回！

---

## 4. 平台画幅与生图 Prompt 合规性 (Multi-Platform Prompt Gate)

- 📐 **画幅标记精准匹配**：
  - 小红书版 Prompt 必须包含 3:4 比例标记（`3:4 aspect ratio` / `--ar 3:4`）。
  - 微信公众号版 Prompt 必须包含 2.35:1 比例标记。
  - 视频号/抖音版 Prompt 必须包含 9:16 竖屏比例标记。
- 🎨 **视觉风格灵活性**：Prompt 应配合封面大标题与物理隐喻，自由选用兼具视觉冲击力与自媒体传播力的美学画风，保持画面清爽高对比。
