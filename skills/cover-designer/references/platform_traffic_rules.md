# 自媒体各平台流量推荐机制与封面排版规范 (Platform Traffic & Cover Layout Rules)

本指南针对小红书、微信公众号、视频号、抖音、B站等自媒体平台的流量推荐算法、用户浏览习惯及信息流（Feed）卡片展示机制，为 `cover-designer` 提供各平台封面的专属排版与画幅规程。

---

## 1. 小红书 (Xiaohongshu) 流量机制与封面规程

### 流量推荐与算法喜好
- **双列瀑布流点击率（CTR）优先**：小红书首页为 2 列纵向瀑布流，封面是获得“初始曝光池”推荐的核心命脉。
- **色彩与视觉抓眼**：喜欢**高对比度、呼吸感强、带有极强痛点/悬念 Hook 标题**的封面。
- **黄金画幅**：**`3:4` (1080x1440)** 是点击率最高的画幅比例（占用屏幕高度最大，曝光面积最大）。

### 视觉排版规程
- **顶部 Y: 0 - 150px**：保留留白，避免被小红书 App 标签遮挡。
- **主标题（10~14字）**：字号 $\ge 72px$ 极粗体，搭配亮黄/鲜红/亮青高光底色或黑线手绘包边。
- **评论区引导标记（条件按需开启）**：仅当内容天然具备【争议/避坑/悬念/痛点/认知差】互动切口时，在右上角或底部显式展示（如 `👉 评论区留下你的观点`）；若内容为纯硬核原理/线性指南教程，评论引导设为 `null`，严禁硬塞机械套路。
- **画面主体**：纯白或浅淡渐变背景（`#FFFFFF`），黑色手绘线条，具象 2D 物理隐喻与 IP Mascot 发问姿态。

## 2. 微信公众号 (WeChat Official Account) 流量机制与封面规程

### 流量推荐与展示场景
- **订阅常态与看一看推荐**：公众号封面分为 **大图头图 (2.35:1)** 与 **小图次图 (1:1)** 两种展示形态。
- **看一看与信息流**：大图头图在信息流中会展现为 `900x383` 的超宽横幅，文字需集中在中央 `16:9` 安全区内。

### 视觉排版规程
- **头图黄金画幅**：**`2.35:1` (900x383)** 横版画幅。
- **次图黄金画幅**：**`1:1` (500x500)** 正方形画幅。
- **排版安全区**：所有爆款标题与 IP Mascot 主体集中在中央 70% 区域，四周保留 15% 呼吸边缘，防止在不同手机屏幕适配时裁切。

---

## 3. 视频号 / 抖音 / B站 (Short Video & Bilibili) 流量机制与封面规程

### 流量推荐与展示场景
- **全屏沉浸流与推荐广场**：视频号与抖音为单列全屏沉浸流，默认抽取视频第 0 秒；B站/横屏视频为 16:9 卡片。

### 视觉排版规程
- **竖屏比例**：**`9:16` (1080x1920)**
- **横屏比例**：**`16:9` (1920x1080)**
- **四区隔离防 UI 遮挡**：9:16 竖屏必须遵守顶部 200px / 底部 320px UI 避让留白区。
