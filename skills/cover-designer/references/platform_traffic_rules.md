# 自媒体各平台流量推荐机制与封面排版规范 (Platform Traffic & Cover Layout Rules)

本指南针对小红书、微信公众号、视频号、抖音、B站等自媒体平台的流量推荐算法、用户浏览习惯及信息流（Feed）卡片展示机制，为 `cover-designer` 提供各平台封面的专属排版与画幅规程。

---

## 1. 小红书 (Xiaohongshu) 流量机制与封面规程

### 流量推荐与算法喜好
- **双列瀑布流点击率（CTR）优先**：小红书首页为 2 列纵向瀑布流，封面是获得“初始曝光池”推荐的核心命脉。
- **色彩与视觉抓眼**：喜欢**高对比度、呼吸感强、带有极强痛点/悬念 Hook 标题**的封面。
- **黄金画幅**：**`3:4` (1080x1440)** 是点击率最高的画幅比例（占用屏幕高度最大，曝光面积最大）。

### 视觉排版规程
- **顶部与四周呼吸留白安全区 (Top Margin Safety Zone)**：标题文字**绝对不能紧贴画布最顶端边缘**！顶部必须预留垂直呼吸留白 padding，确保标题置于上半部分的内缩安全区内，避免拥挤挤压感或被 App 标签遮挡。
  - ⚠️ **英文 Prompt 禁忌**：英文生图 Prompt 中**绝对不能写入 `15%`、`20%` 等百分比数字**（AI 生图模型会将 Prompt 中的 `15%` 误判为要在顶部绘制的文字标签），须统一使用纯英文定性词描述：`generous top margin, spacious edge padding, centered upper safety zone`。
- **主标题（10~14字）**：字号 $\ge 72px$ 极粗体，居中内缩排版，搭配高对比高光底色或包边，周围大面积留白。
- **视觉构图主次分明与自适应 (Adaptive Focus Layout)**：若有天然贴切的物理隐喻，可在画面中央采用单一强焦点隐喻主体；**若无合适隐喻，严禁强塞生硬比喻**，果断采用极简大字 Typography 排版或纯净概念插画。无论使用何种版式，色彩须高对比，周围大面积留白，绝不搞左右分割或多场景散乱堆叠。
- **文字排版清晰防杂乱 (Clean Typography & Anti-Clutter)**：英文生图 Prompt 聚焦于表达核心意思的有效文字（主标题及必要的副标题切口），杜绝影响核心表达或分散注意力的乱码伪字符与无用装饰噪点。
- **评论区引导标记（条件按需开启）**：仅在中文设计逻辑中呈现；英文生图 Prompt 保持纯净无小字干扰。

## 2. 微信公众号 (WeChat Official Account) 流量机制与封面规程

### 流量推荐与展示场景
- **订阅常态与看一看推荐**：公众号封面分为 **大图头图 (2.35:1)** 与 **小图次图 (1:1)** 两种展示形态。
- **看一看与信息流**：大图头图在信息流中会展现为 `900x383` 的超宽横幅，文字需集中在中央 `16:9` 安全区内。

### 视觉排版规程
- **头图渲染画幅**：**`16:9` (1920x1080)**。
- **次图黄金画幅**：**`1:1` (500x500)** 正方形画幅。
- **排版安全区**：所有爆款标题与 IP Mascot 主体集中在中央 70% 区域，四周保留 15% 呼吸边缘，防止在不同手机屏幕适配时裁切。

## 3. 视频号 / 抖音 / B站 (Short Video & Bilibili) 流量机制与封面规程

### 流量推荐与展示场景
- **全屏沉浸流与推荐广场**：视频号与抖音为单列全屏沉浸流，默认抽取视频第 0 秒；B站/横屏视频为 16:9 卡片。

### 视觉排版规程
- **竖屏比例**：**`9:16` (1080x1920)**
- **横屏比例**：**`16:9` (1920x1080)**
- **四区隔离防 UI 遮挡**：9:16 竖屏必须遵守顶部 200px / 底部 320px UI 避让留白区。
