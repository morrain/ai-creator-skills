# 手绘视觉风格指南 (Hand-Drawn Style Guide)

本文档为 `to-poster` Skill 的核心视觉风格标准参考。本 Skill **统一使用 Q 版软萌图文科普风格 (Cute Q-Style Educational Infographic)**，所有海报描述与生图 Prompt 须严格遵循以下规范。

---

## 🌟 Q 版软萌图文科普风格规范 (Cute Q-Style Educational Infographic Standard)

### 1. 整体画风基调

- **风格关键词**：Q 版软萌 / 手绘涂鸦 / 图文科普 / 知识卡片 / 小红书风格
- **线条质感**：黑色软墨水手绘勾线，线条带轻微不规则感，具有手绘温度感。
- **整体质感**：插画 + 文字融合排版，图文各占约 60% 和 40%，视觉饱满但不压迫。

---

### 2. 背景与纸张质感

- **背景色**：暖米白 / 羊膏白（非纯白 `#FFFFFF`，而是接近 `#FAF6F0` 的偏暖米色）。
- **纸张纹理**：细腻手绘纸张纹理，呈现轻微的纤维与颗粒感，营造真实手账感。
- **Prompt 关键词**：`暖米白羊膏纸质感背景` / `warm off-white cream paper texture`

---

### 3. 配色方案：莫兰迪粉彩系 (Morandi Pastel Palette)

采用柔和低饱和度的莫兰迪色彩组合，避免刺眼的荧光色或冷硬高对比色彩：

- **基底色**：暖米白 `#FAF6F0`
- **线条色**：柔和炭黑 `#2C2C2C`
- **辅助强调色**：
  - 莫兰迪蓝 `#7B92A7`（用于科技概念、系统架构）
  - 莫兰迪橙 `#E89C7D`（用于重点警示、核心金句）
  - 莫兰迪绿 `#8FA89B`（用于正确示例、推荐方案）
  - 莫兰迪黄 `#E6C587`（用于标签底色、亮眼卡片）

---

### 4. 画面构图与比例 (3:4 Aspect Ratio)

- **图像比例**：统一采用 **3:4 黄金长宽比**（`--ar 3:4`），完全契合移动端自媒体平台（如小红书、即刻、微信朋友圈）的屏幕阅读体验。
- **留白规则**：四周保留至少 8% 的呼吸空间，避免文字与手绘图案紧贴画布边缘。
