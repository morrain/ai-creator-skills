# 手绘海报审查 SubAgent 裁决与审查标准手册 (Poster Reviewer Standards)

本文档为海报审查 SubAgent 在对图文海报方案进行**阶段一（海报整体拆分审查）**、**阶段二（N 个并发 SubAgent 独立单张海报审查）**以及**阶段三（社媒发布文案审查）**时的唯一诊断与裁决依据。审查 Agent 必须保持严谨、客观与美学把控视角，坚决打回文案混乱、Prompt 简陋、缺失去乱码控制指令或包含 Markdown 源码符号的方案。

---

## 一、 审查流程与诊断输出规范

### 1.1 审稿人决策机制
海报审查分为三个阶段：
- **阶段一（整体拆分审查）**：由 1 个全局海报审查 SubAgent 对 N 张海报的总体拆分蓝图（破题/对比/架构切片/金句闭环）进行评审。
- **阶段二（多 SubAgent 并发审查）**：同时并行启动 N 个独立的海报审查 SubAgent (SubAgent 1..N)，每个 SubAgent 专精审查对应的第 i 张海报说明文档与 Prompt，独立给出裁决：
  - **`[PASS]`**：该张海报结构清晰、版式匹配、视觉组件丰富、防杜撰/去乱码指令严密、Prompt 饱满，可直接保存归档至 `assets/poster_i.md`。
  - **`[REJECT]`**：存在扣分项，输出针对该张海报的结构化诊断报告与可操作重写指令。
- **阶段三（发布文案审查）**：审查 `poster_post.md` 的纯文本标记隔离与 H1 标题包含性。
- **重试上限控制**：每个阶段/分支独立的打回重写上限为 **8 次**。

### 1.2 单张海报审查 SubAgent 诊断报告格式
```markdown
### 🎨 单张海报审查 SubAgent 诊断报告 (Poster SubAgent #i Audit Report)

**审查目标**：海报 [i] - [海报主题]
**裁决结论**：[PASS / REJECT]
**质量评分**：XX / 100

#### 1. 扣分项与问题定位
- ❌ **[扣分维度]**：问题描述与具体修改指导。

#### 2. 结构化重写指令 (Revision Guide for Writer Agent)
1. **[指令 1]**：补充生图 Prompt 中的防杜撰指令 `strictly NO fake subtext underneath capsule headers`...
2. **[指令 2]**：调整视觉组件，增加手绘悬挂小吊牌与底部黄色气泡金句总结框...
```

## 二、 阶段一：【海报整体拆分方案审查标准】(Overall Poster Plan Audit)

全局海报审查 SubAgent 评估 N 张海报的总体拆分方案时，须评估以下核心维度：

### 1. 全文干货浓缩度 (Full-Text Value Compression)
- **卡片承载**：N 张海报（通常 3-6 张）是否完整提炼并重构了正文文章的核心干货与认知金句？
- **故事线连贯性**：拆分蓝图是否形成了清晰的组图故事线（如：海报 1 破题/Hero封面 -> 海报 2 痛点对比 -> 海报 3~N 架构/干货切片 -> 末页 金句速查闭环）？
- **禁忌**：严禁出现干货密度极低、无实质内容的“废话卡片”。

### 2. 拆分逻辑与版式映射契合度 (Split Rationality & Layout Mapping Audit)
- **数量适度**：海报张数 N 是否契合多图文自媒体平台（如小红书 3-6 张滑动组图）最佳浏览节奏。
- **版式映射控制**：检查 N 张海报的版式挑选是否精准匹配了内容属性矩阵（如避坑点是否使用了避坑拆弹卡片，指标测评是否使用了数据面板版），严禁全篇机械使用单一排版。

## 三、 阶段二：【单张海报并发审查标准】(Per-Poster Parallel SubAgent Audit)

针对第 i 张海报，对应的专职海报审查 SubAgent i **独立深入审查**以下核心维度：

### 1. 显式文案完整性与防杜撰/去乱码指令 (Explicit Text & Anti-Gibberish Audit) —— 核心硬指标
- **防杜撰/去乱码约束**：生图 Prompt 中必须**显式写入纯净文本控制指令**（`strictly NO fake subtext underneath capsule headers, NO random garbled text/gibberish, NO unintended bullet points, only render explicitly specified text inside single quotes`）。坚决打回可能导致生图模型在胶囊标题下产生乱码或虚假列表的 Prompt。
- ❌ **原生中文文案保留**：检查 🟢 英文生图版 Prompt 中，单引号 `'...'` 括起来要求渲染在海报上的核心标题/文案是否保持了原生中文。若发现被错误翻译成英文（如把 `'SA 负责画饼...'` 翻译为 `'SA talks...'`），必须直接判定 `[REJECT]` 打回并要求修正为原生中文。

### 2. 版式契合度与视觉组件多样性 (Layout & Visual Component Audit)
- **版式匹配**：从 10 大经典版式库中选择的版式是否与该卡片知识结构高度契合？
- **组件弹性组合**：根据海报版式选择最契合的 2-4 个精细手绘视觉组件（如卡片框、莫兰迪胶囊标题、悬挂吊牌、气泡总结框、放大镜等），确保层次清晰且保持舒服的留白。

### 3. 小智 IP 姿态与正文插图隐喻继承 (Xiao Zhi Mascot & Metaphor Inheritance)
- **动作具象化与跨媒介继承**：小智（Xiao Zhi）姿态必须具备场景感，且**必须优先继承并延伸该章节在正文插图配置 (`assets/illustration_*.md`) 中的隐喻印记与小智动作**（例如：正文插图设定为小智操作三棱镜，海报必须延伸为小智拿着三棱镜拆解要素），形成强烈的跨媒介视觉联动，严禁脱节或画成无意义静态摆件。

### 4. Prompt 饱满度与美学参数 (Morandi Style & Rich Prompt Audit)
- **生图 Prompt 规范**：必须具备丰富具体的画面构图、背景纹理（暖米白羊膏纸 `#FAF6F0`）、配色方案（莫兰迪粉彩）、手绘黑色勾线与 3:4 宽高比例。

## 四、 阶段三：【200 字爆款发布文案审查标准】(Poster Post Audit)

- **标题矩阵 (必须包含原文大标题 H1)**：提供 3-5 个带 Emoji 的吸睛标题。**第一备选项必须显式保留母版长文的原正文大标题 H1**，随后再附带痛点型、干货型、悬念型标题。
- **纯文本隔离控制 (Clean Plain Text Check)**：必须检查全文是否全量使用纯文本格式，**绝对严禁出现加粗 `**`、斜体 `*`、标题 `#` 或链接 `[text](url)` 等 Markdown 语法标记**（防止用户粘贴到小红书、朋友圈、即刻等自媒体平台时显示源码解析错误）。
- **Hook 与干货总结**：前 3 行强 Hook 共鸣，配以极简列表化要点指南。
- **互动与标签**：包含互动引导与 5-8 个精准 `#话题` 标签，适合小红书/多平台直接复制发布。
