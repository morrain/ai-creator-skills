# 微信公众号长文审稿标准手册 (WeChat Article Reviewer Standards)

本文档为微信公众号离线排版 HTML 的审查标准手册。审稿人必须客观严谨打分并给出结构化裁决。

---

## 审查维度与判定标准

### 一、 核心否决项 (Fatal Rejection Rules - 一票否决)

出现以下任意情况，必须直接裁决为 **`[REJECT]`**：

1. **Markdown 表格残留**：
   - 全文包含任何形式的 `| col1 | col2 |` 原生 Markdown 表格语法。
2. **核心知识点缺失**：
   - 相比于输入母版长文，丢失了核心干货、关键代码逻辑或重要论点。
3. **篡改原文或擅自插入提炼总结卡片 (一票否决)**：
   - 正文包含了原文中未出现的 AI 提炼总结卡片、新增段落，或擅自修改、增删了原文句子。高亮提示必须且仅能通过 `<span style="...">` 标签精准包覆原文已有词句（注意：正文最末尾的 `🔥 结尾互动与引导关注卡片` 属于标准排版组件，不视为擅自插入）。
4. **缺失结尾互动关注卡片 (一票否决)**：
   - 文章最末尾缺失 `🔥 结尾互动与引导关注卡片`（组件 7）或该组件样式不完整。

---

## 二、 排版与移动端视觉体验标准 (Mobile UX & Layout Standards)

1. **表格解构与 HTML 内联卡片化**：
   - 是否使用双色 HTML 浅底边框卡片（`🔴 传统痛点` vs `🟢 新架构优势`）或步骤卡片（`🚀 阶段一`）重构表格。
2. **视觉卡片分层与 HTML 内联组件**：
   - 二级标题采用居中 + 浅蓝胶囊与下划线；三级标题采用靠左对齐 (`text-align: left`) + 左侧极光蓝竖向边框。
   - 爆款金句统一使用 **`💡 金句总结`** 暖金虚线边框卡片（组件 5，`#FFF9F0` 浅黄底 + `#FA9D3B` 虚线边框）。
3. **正文插图与图注组件**：
   - 图片统一置于 `text-align: center` 居中容器中，设置 `max-width: 100%`，且下方带有显式居中的灰色斜体中文图注说明（`💡 图 1：...`）。图片路径按 `illustration_N` 主干扫描匹配实际存在的扩展名（如 `.png` / `.jpg` / `.jpeg` / `.webp`），不得误判写死后缀。
4. **正文段落适度点睛高亮**：
   - 高亮/下划线标注精炼适度（每个二级标题小节控制在 2~3 处点睛即可），避免高亮过多造成视觉疲劳。
5. **结尾互动引导关注卡片**：
   - 确认最末尾包含背景色 `#F8F9FA` 的完整互动关注卡片，包含精简的项目生成说明（`💡 本文由 Agent 使用 ai-creator-skills 自动生成。` 与 `涵盖爆款长文写作、认知插画、微信排版、海报生成与视频动画创作`）、留言或私信获取引导句，以及“点赞 + 在看 + 转发”提示。
